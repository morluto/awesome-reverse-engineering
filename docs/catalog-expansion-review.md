## Reading the evidence

- GitHub source references are pinned; the three official websites are dated observations without immutable source commits.
- Default-branch activity and published releases are recorded separately. Redress, for example, has an older default-branch snapshot and a 2026-10-20 release; it is not labelled mothballed on that basis.
- ReClass.NET documents Linux support tested on Ubuntu 18.04. Dumpulator contains explicit WOW64 handling. r2flutter documents Android and iOS containers and version-dependent layouts. Old automated host/version claims were checked against those sources rather than repeated.
- flare-emu is archived and documents IDA, Rizin and radare2 integration; no Ghidra integration is asserted.
- Hextree offers paid courses alongside free material. UModel leaves licensing undetermined on its official page. API license values in the JSON are not a full component or sample-file license audit.
- Native Windows/macOS GUI runs, hardware experiments, real memory dumps, game assets and full formal-analysis environments were not exercised by this source review.
